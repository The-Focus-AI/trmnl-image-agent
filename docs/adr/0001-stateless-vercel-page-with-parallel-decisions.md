# Stateless Vercel HTML Endpoint Backed 100% by Parallel Web Systems and CDN SWR

We replaced the hourly `hermes` → AI image → `git push` → GitHub Pages pipeline (which bloated `.git` past 2.4 GB) with a stateless Vercel endpoint pointed to directly by TRMNL's Screenshot plugin, warmed via Vercel Cron and `Cache-Control: stale-while-revalidate` so responses stay well inside TRMNL's 5-second screenshot timeout without introducing a database. For data ingestion, PDF parsing, editorial triage, and copy synthesis, we pair public NWS/USGS JSON feeds strictly with **Parallel Web Systems** (`/v1/extract` including monthly *Cornwall Chronicle* PDFs, `/v1/search`, `/v1/decisions`, and `/v1beta/chat/completions` structured `json_schema` outputs), running the entire storefront pipeline on a single vendor API key (`PARALLEL_API_KEY`).
